# 3 分钟分清 Plus、Codex 和额度：第一次买，先别买错

作者：路飞AI · 核对日期：2026-10-13 · [返回教程首页](../README.md)

“我想用 ChatGPT，应该买 Plus 吗？”“Codex 没额度了，再买一个 Plus 就行吗？”

先把需求写成一句话：**你是想聊天和处理文件，还是让工具执行任务，又或者只是当前用量不够？**

## 1. 先分清四个名字

| 名字 | 小白可以怎样理解 | 购买前要确认 |
| --- | --- | --- |
| ChatGPT | 你登录账号后使用的产品 | 自己的账号能否正常使用 |
| Plus 等套餐 | 账号的订阅方案 | 到账到哪个账号、期限及适用条件 |
| Codex | 面向软件开发的工作工具 | 使用入口、登录方式和账号权限 |
| 卡密 | 用于交付和兑换的代码 | 它实际兑换的是什么，不是只看名字 |

订阅和充值卡是不同层面的东西：**订阅是账号权益，卡密是兑换凭据。** 支付了卡密费用，不代表兑换已经完成。

ChatGPT 有网页、桌面等入口；开发者也可选择 Codex 的终端或编辑器入口。选择适合自己的入口即可，不必一开始把所有客户端都装上。[官方入门说明](https://learn.chatgpt.com/docs/quickstart)

## 2. 按你的目标选择下一步

### 想开通或续订 Plus

先确认账号能够正常登录，再核对商品说明中的地区、期限、现有订阅限制。不要把“新开通”和“续费”当成一定通用。

继续读：[Plus 充值流程](02-plus-recharge.md)。

### 想让 Codex 帮你改代码

先尝试一个能验收的小任务，比如解释一个文件、修复一个明确的报错。比“帮我做一个完整项目”更容易判断工具是否适合自己。

继续读：[Codex 入门](03-codex-getting-started.md)。

### 已经在用 Codex，只是提示用量不足

记录提示内容与重置时间，确认是否是额度限制，再比较等待重置、缩小任务、调整套餐或额外额度等路径。

继续读：[额度专题](04-codex-credits.md)。

### 看到了好友邀请或学生活动

活动服务不是人人可用的“通用便宜套餐”。资格没有确认前，不要因为价格低就付款。

好友邀请先查[本站资格页面](https://invite.lufeiai.shop/)；学生服务要核对官方活动与真实在读资格，不能使用虚假材料。

## 3. 第一次购买前的五项检查

- 账号是自己的，自己能登录。
- 商品权益和你的目标一致。
- 已读期限、地区、资格与退款说明。
- 知道是自动发卡还是人工发货。
- 知道卡密收到后应该在哪里使用。

这五项有一项不明确，就先问清楚。特别是打不开页面、登录失败或验证失败，不要把“再充值一次”当成排查方法。

## 4. 为什么不建议直接买陌生人的现成账号？

教程推荐以自己可控制的账号为中心核对权益，而不是用“有账号密码”代替安全检查。

陌生账号可能涉及多人共用、找回、历史违规或订阅来源不明。卖家承诺“绝对不封”也不等于官方保证。

**先能正常使用，再买自己确实需要的权益。**
